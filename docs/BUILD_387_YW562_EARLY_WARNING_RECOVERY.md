# AI Data Platform Build 387

Build 387 adds early-warning recovery tracking, degradation-remediation effectiveness review, and multi-horizon baseline restoration auditing.

- Active Build 386 early warnings require durable recovery observations.
- Remediation is effective only when independently verified and the restored score meets or exceeds the pre-degradation score.
- AI Hub, Comms Hub, and AI Data Platform must all acknowledge warning closure.
- 6h, 24h, and 72h baseline restoration evidence is required before degraded runtime state can close.
- Repository/deployment GREEN cannot close an open runtime warning.

Build 387 also introduces the Master Shell Instrument UI System derived from the approved interface specification. The first application of this theme is the AI Data Platform Master Command Center, Outer Sysop Shell, and the Yard Workers/iCamp source-shell oversight page.
