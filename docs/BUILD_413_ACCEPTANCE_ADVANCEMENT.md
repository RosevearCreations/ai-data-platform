# AI Data Platform Build 413

**Seven-Application Role/Device/Accessibility/Performance/UX Acceptance & +10-Point Evidence Advancement**

Build 413 binds the existing role/device, performance, experience-telemetry and completion systems into one evidence-driven acceptance layer across all seven applications.

## Acceptance evidence

Each application requires current evidence for:
- Role/device acceptance
- Accessibility
- Performance
- UX
- Loading/degraded-state behavior

A PASS requires at least 90% measured acceptance, zero critical failures, owner review and independent verification. Missing or stale evidence remains unresolved.

## Completion advancement

Every application retains the seven Build 338 completion axes:
design, implementation, automated testing, integration verification, security, accessibility/device acceptance and production user acceptance.

For every application/axis pair, Build 413 requires a locked baseline denominator and a target of at least baseline +10 percentage points, capped at 100. Advancement counts only when current independent evidence reaches that target with the same denominator hash.

Production GREEN, simulated tests, missing evidence or a changed denominator cannot create completion progress.

## Unified Server Shell experience

The three Server Shell modules retain one navigation language and independently selectable certified presentation profiles:
- Night Ops
- Copper Workshop
- Meadow Grid

Theme selection is owner-gated and append-only. Theme/color/background choices cannot alter semantic security or health status meaning and cannot hide security state.

## Slave-shell acceptance

Yard Workers and iCamp receive clear slave-shell acceptance panels. Their operational data and tenant authority remain local to those product shells; AI Data Platform consumes governed acceptance evidence only.

## Persistence

Migration 0176 adds forced-RLS append-only evidence ledgers for Build 413 acceptance evidence, completion advancement evidence and Server Shell theme-selection events.

Final governance state when all evidence is current and valid:

SEVEN_APPLICATION_ACCEPTANCE_AND_ADVANCEMENT_ASSURED
